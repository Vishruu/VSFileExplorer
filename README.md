# VS File Explorer

A powerful, all-in-one Android file manager with built-in encryption, cloud sync, and advanced tools.

![Platform](https://img.shields.io/badge/Platform-Android-green)
![Language](https://img.shields.io/badge/Language-Kotlin-purple)
![License](https://img.shields.io/badge/License-MIT-blue)

## ✨ Features

### 📁 File Management
- Browse, copy, move, rename, delete files & folders
- Multi-select with long press
- Grid & list view modes
- Sort by name, size, date, type
- Hidden files support
- Bookmarks & Recent files

### 🔒 Security
- **AES-256-GCM** file encryption
- **Secure Vault** with second space
- **App Lock** with fingerprint + password
- **File Shredder** (3-pass overwrite)
- **Secure Notes** (encrypted)
- **Recycle Bin** with auto-delete

### ☁️ Cloud & Network
- **Google Drive** integration
- **WiFi Transfer** (browser-based)
- **FTP/SFTP** client
- **Network Storage** (SMB)

### 🛠️ Tools
- **Text Editor** (built-in)
- **PDF Viewer** (password-protected support)
- **Duplicate Finder** (SHA-256 hashing)
- **Storage Analyzer**
- **App Manager** (backup APKs)
- **Image Viewer**
- **Audio Player**
- **ZIP/Unzip**

### 🎨 UI/UX
- Material 3 design
- Dark/Light/AMOLED themes
- Custom accent colors
- Custom fonts
- Home screen widget
- App shortcuts
- Smooth animations
